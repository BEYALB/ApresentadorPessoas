# 👋 Apresentador de Pessoas

Um projeto simples desenvolvido com **HTML, CSS e JavaScript** para praticar manipulação do DOM e interação com o usuário.

## 🚀 Sobre o projeto

O usuário digita um nome e, ao clicar em **"Apresentar"**, o sistema exibe uma mensagem personalizada na tela e limpa o campo de entrada.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- ✏️ Entrada do nome da pessoa
- 👋 Mensagem personalizada
- 🧹 Limpeza automática do campo após a apresentação
- 📱 Interface simples

## 🎯 Objetivo

Projeto desenvolvido para praticar:

- Manipulação do DOM
- `querySelector()` e `getElementById()`
- Manipulação de `.value` e `.textContent`
- Funções em JavaScript
- Eventos e interação com elementos HTML
